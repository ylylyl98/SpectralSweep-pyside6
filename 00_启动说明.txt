SpectralSweep 启动说明
====================

EXE 用户：推荐从 GitHub Releases 下载 SpectralSweep-<版本>-windows-x64-Setup.exe
及配套 .exe.sha256。正常结束测量并关闭主程序和 worker 后运行安装器。
安装器只安装到当前用户，默认目录 %LOCALAPPDATA%\Programs\SpectralSweep，
不要求管理员权限；有开始菜单和可选桌面快捷方式。完成后请自行启动。
升级可运行新 Setup，卸载可使用 Windows“已安装的应用”；保留用户设置与实验数据。
检测到程序仍运行时安装器会停止，不自动关闭仪器进程，不自动重启。

便携 ZIP 仍保留：全部解压后运行 SpectralSweep.exe，保留同目录的
SpectralSweep-worker.exe 和 _internal。Setup 与 ZIP 均无需另装 Python。
仪器驱动、厂商软件和本机配置仍需按实际设备准备。
官方下载：https://github.com/ylylyl98/SpectralSweep-pyside6/releases

更新程序
--------
旧版先手动安装一次新 Setup（或换用新版完整 ZIP），才能获得应用内更新提醒。
Help > Check for updates… 或状态栏 Updates 打开检查窗口，也可调整更新通道和自动检查。
发布版默认运行期间每 6 小时检查；预发布版默认包含预发布，稳定版只检查正式版。
程序关闭时不检查；网络异常或 GitHub 限流可能延后检查，测量中延后自动弹窗。
检查仅提示并打开本仓库官方发布页，不自动下载、安装或重启。
结束测量并正常退出后，再自行下载、运行新 Setup；源码版本继续通过 Git 更新。

源码用户：双击本说明旁边的 launch.bat。
这是源码项目的主程序 BAT 入口，会打开 SpectralSweep 测量界面。
默认使用 Qt Quick 界面；需要兼容旧界面时可加 --ui widgets。
不要从搜索结果里的 tmp 子目录或旧工程副本启动。

源码第一次启动会检查、安装 Python 依赖，可能需要联网并等待。
以后依赖没有变化时会直接启动。正常使用不需要手动运行任何其他脚本。
请保留 launch.bat 在项目根目录；需要快捷方式时，给它创建快捷方式即可。

------------

docs/usage-reference.md     原 README 的详细操作与开发参考
docs/manuals/               仪器手册
docs/screenshots/           界面参考截图
docs/reference/notebooks/   旧实验 Notebook（不是主程序入口）
docs/reference/scripts/     旧实验参考脚本
docs/reference/README.md    参考文件清单及 Notebook 工作目录说明
tools/                     开发、维护、仪器诊断工具，见 tools/README.md
scripts/                   专项实验脚本

calibrations/               标定资料
commissioning_evidence/    调试验证记录

app、controllers、ui、utils、CRYO2100、andor dll 等是程序或驱动目录。
根目录的 main.py、iv_automation.py、lf6_automation.py、TLPMX.py、
TLPMX_64.dll、config.json、requirements.txt 也是程序所需文件，保持原位。
.venv-pyside6-* 是本机 Python 环境，.runtime 是本机运行库。

特殊用途（在本项目根目录的 PowerShell 中运行）
-------------------------------------------
只检查/安装依赖： .\launch.bat --install
升级依赖后启动：  .\launch.bat --update-deps
独立光谱模拟预览：.\launch.bat --preview-spectrum
完整界面隔离预览：.\launch.bat --preview-workspaces（9页，设备断开，F5重载）
兼容旧界面：      .\launch.bat --ui widgets

tools/winspec 下的 run_*.cmd、update_*.cmd 用于相机服务、诊断或维护，
不用于打开 SpectralSweep 测量界面。日常启动无需逐个尝试。
