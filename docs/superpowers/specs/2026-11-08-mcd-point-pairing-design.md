# MCD 逐点稳场 A/B 配对方案

状态：已实现可选的逐点配对采集模式，并通过模拟回归验证；尚未实机验证。现有连续扫场模式保留为默认模式。

## 已确认的参数选择

- MCD1000、MCD2100 的新逐点配对模式默认磁场容差为 **10 mT（0.010 T）**，允许用户修改。
- 判定采用 `abs(B_readback - B_target) < tolerance_t`，即默认误差严格小于 10 mT。
- 持续稳定时间（s）作为独立的用户可设参数，工程初始值为 1 s，可修改。这不是厂家稳定时间。
- 磁场步长（mT）由用户自行设定，初始值为 50 mT；50 mT、100 mT 不是固定档位。

## 采集流程

1. 为每个栅压条件及扫场方向生成包含端点的明确磁场点列。
2. 到达目标场并保持，满足用户设置的磁场容差和持续稳定时间。
3. 转到 A 角度并检查磁场后采谱；转到 B 角度并再次检查后采谱。
4. 保存每次曝光前后的实际磁场及配对标识，验证配对后进入下一点；不以目标场替代实际读数。

在连续轮询期间累计稳定历史，超出容差则重置稳定计时。当前转角与曝光期间没有连续磁场采样，因此转角后重新进行完整稳场检查。每次曝光前后的场值都必须距目标小于容差，而且整对 A/B 的四个场读数的最大差必须小于同一容差。读数不合格即拒绝配对并停止，保留已采原始光谱及未完成/拒绝记录；曝光前后检查不能证明曝光内每个时刻的磁场。

正向与反向分别包含自己的起终点，因此回程在转折场重新采一对。1000 的配对状态记录在与原始 CSV 同名的 `.pairs.jsonl`，2100 记录在条件元数据的 `point_pairs`。两者 CSV 均记录实际曝光前后磁场、目标场和配对编号。

## 两种设备的控制路径

- MCD1000：到达目标后确认暂停，保持 Driven/加热器所需状态，使用针对保持状态的稳定检查；不能沿用要求持续扫场的判据。
- MCD2100：保留目标设定与磁场控制，要求控制状态为 IDLE、设定值读回相符并满足容差及持续稳定时间；曝光后再次检查。正常保持不以 Stop 作为实现方式。复用现有准备、温度、栅压及安全检查。
- 步长不自动改变硬件扫速。预计移动时间应依据当前速率分段及跨段路径计算，稳场和曝光时间另外计入；本次尚未增加分段扫速的时长预测界面。

## 10 mT 默认值的依据和限度

用户提供的厂家网页 JavaScript 中，`magnetFieldDisplay`（模块 `2f6a`）使用以下条件显示磁场数值旁的勾号：

```javascript
isTargetReached: function() {
    return Math.abs(this.H.value - this.target) < .01
}
```

父组件以 `[T]` 标注磁场单位并传入 `HSetPoint.value`。因此这里的界面阈值为 0.01 T（10 mT）。该条件本身没有持续稳定时间、变化率或 `MagnetStatus === "IDLE"` 检查；目标值还经过界面数值格式化。

这是厂家网页的显示规则，不是已经确认的固件内部结束扫场判据，也不能单独证明曝光期间磁场稳定。网页的 Apply 后 10 秒限制、错误消息刷新及编辑后更新限制均不作为稳场时间依据。

IDLE 与 Driven 属于不同状态维度。历史实机记录 `commissioning_evidence/attodry2100_continuous_002_to_003_20260821T055054Z.json` 的 preflight 快照同时包含 IDLE、driven=true、persistent=false、field_control=true。逐点模式要求 IDLE 是基于该证据的保守到位检查，不是厂家已确认的必要稳场条件；不通过 Stop 切换到 IDLE，不切到 Persistent。连续模式不增加此要求。

10 mT 默认值只用于新逐点配对模式。现有连续模式、磁体全局容差、准备检查及旧离散 worker 保持各自的参数语义。
