# Qt Quick 全页布局审查

默认 `main.py` / `launch.bat` 使用 Quick；`--ui widgets` 保留兼容入口。
`--preview-workspaces` 在临时配置、历史和 QSettings 下打开全部 9 页，设备保持断开，
测量与连接动作被禁用。预览可以编辑布局、参数和表格，F5 只重启预览子进程。

## 问题与实施

| 观察到的问题 | 已实施的修改 |
| --- | --- |
| 原默认入口仍是 Widgets，局部 QML 的视觉样式不同 | 默认切换 Quick；统一 Basic 控件、语义颜色、字体、焦点/禁用/错误状态与深浅主题，原生容器使用相同调色板 |
| 1024×768 被隐藏页面的最小高度撑高 | 固定导航与命令区；只根据当前页面计算正文最低高度，正文及内部参数区按需要滚动 |
| 命令区占多行，右侧留出大量空白 | 标题、状态、参数和动作合并为自适应 Flow；运行与停止始终位于固定区 |
| 字号与控件占高偏大 | 正文采用 12px、主要控件 28px、原生宿主 9pt；保留完整读数、焦点状态和标签换行，不以裁切换取密度 |
| 窄窗口仪器侧栏挤占实验正文 | 低于 1200px 时仪器作为单独视图打开；导航回工作区恢复正文，菜单/快捷键遵循同一规则 |
| 双栅预览被安全设置、执行顺序、文件名和运行详情推到折叠线下 | 右栏优先展示真实执行序列；Safety、Execution order、Filename、Run details 可展开；保留安全短摘要和就绪提示 |
| 表单将标签和输入框断开，Grid 的 Start/Stop 标签与值分离 | 将 label 与 editor 成组排列；依据明确的 buddy 关系合并 Grid；长说明换行，表单高度变动重新计算宿主布局 |
| 一两行表格占用整块区域，宽表格需要横向滚动 | 按记录虚拟化，每条记录内的全部标签/字段自动换行；不横向滚动、不左右翻页、不切字段组；短内容按实际高度收缩 |
| Motion 序列表格固定 13 列且一直显示横向滚动条 | 每条记录的 13 个字段全部在同一视图换行显示，共用原执行顺序与勾选状态，大规模列表按记录虚拟化 |
| MCD / Motion / BFP 长参数栏挤压主要设置与图表 | 将设备遥测、独立新增行工具、文件名详细字段、可选温控/背景设置分区折叠；已启用的温控和背景功能保持展开 |
| 页面迁移后弹窗和侧栏样品控件仍是旧样式 | 迁移明确支持的业务弹窗、样品选择/保存设置及外层侧栏；系统文件/颜色/输入弹窗保留原生行为 |
| 仅凭无异常不能证明功能完整 | 补充真实 QML 输入、按钮、菜单、撤销、校准拟合、取消与重载交互，以及源码异地复制运行检查 |

## 编辑和实验语义

表格使用原 cell control / delegate 的验证，不把文本直接写入未经验证的计划。
输入草稿在命令或页面重载前统一提交；无效数值阻止 Apply/Run，Stop/Abort 仍可用。
Discard/Reset/Undo 等明确纠错动作先清除界面草稿；行结构变化不会把旧编辑 token 写入另一行。
校准表的可编辑下拉框保留手输波长，Spectrum 重载后 Calibration 字段重新绑定新源控件。

科学图表直接绘制数值数组；真实坐标、断轴、共享 Y、参考谱、标定二维图及保存数据语义
继续通过原有领域逻辑验证。详见 [科学图表说明](qt-quick-scientific-plots.md)。
